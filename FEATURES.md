# AfriMatch - Complete Feature Documentation

## 🎯 Overview

AfriMatch is a dual-mode platform combining dating and professional networking for Africa and its diaspora. Users can seamlessly switch between Dating and Professional modes, or use both simultaneously.

---

## 💕 Dating Mode Features

### 1. **Innovative Signup Flow**
- **Mode Selection**: Users choose between Dating, Professional, or Dual Mode during signup
- **Multi-Auth Options**: Email, Phone (OTP), Google, Facebook
- **Age Verification**: Automatic age verification (18+ required)
- **Profile Setup**: Guided profile creation with photo verification

### 2. **Matching System**
- **Swipe Interface**: Intuitive swipe-based matching
- **Advanced Filters**: Age, location, interests, education, income
- **Female-First Matching**: Women control the matching experience
- **Verified Profiles**: KYC verification for safety

### 3. **Communication**
- **Real-Time Messaging**: WebSocket-based instant messaging
- **Message Reactions**: Emoji reactions on messages
- **Typing Indicators**: See when someone is typing
- **Read Receipts**: Know when messages are read
- **Video Calls**: In-app video calling (coming soon)

### 4. **Safety & Trust**
- **Profile Verification**: Photo and ID verification
- **Report & Block**: Easy reporting and blocking features
- **Safety Tips**: In-app safety guidelines
- **24/7 Support**: Dedicated support team

### 5. **Subscription Plans**
- **Basic** ($5/month): 5 likes/day, basic profile, standard matching
- **Premium** ($9.99/month): Unlimited likes, advanced filters, rewind feature
- **VIP** ($19.99/month): All premium + VIP badge, video calls, priority support
